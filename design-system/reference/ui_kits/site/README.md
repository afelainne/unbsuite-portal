# UI kit — UNBSTOOLS marketing site

Design width **1440px**. Open `index.html`.

| File | Surface |
| --- | --- |
| `SiteHeader.jsx` | Sticky translucent header: wordmark, centred pill nav, Sign in + Get started. |
| `SiteHero.jsx` | Centred two-weight headline, button pair, and a full browser-chrome product mock built from real primitives. |
| `SiteSections.jsx` | Benefits grid, dashboard overview band, two-up plan cards (light / black), app download band, and the oversized wordmark footer. |

`Wordmark` is reused from `../workspace/AppShell.jsx` so the site and app share one lockup.

**Placeholders:** the app-band photograph is a labelled inset slot — no photography was supplied.
